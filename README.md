# Bridging Dreams Consulting Website

A Vercel-ready React + Vite website.

## Deploy on Vercel

1. Go to https://vercel.com
2. Click **Add New Project**
3. Upload this folder or connect it through GitHub
4. Use these settings:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Click **Deploy**

## Local preview

```bash
npm install
npm run dev
```

## Customize

Edit:
- `src/App.jsx` for page text and structure
- `src/styles.css` for colors and styling
